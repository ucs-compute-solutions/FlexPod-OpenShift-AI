# IaC using Ansible for FlexPod Baremetal with OpenShift AI CVD 

This repository provides the IaC automation using Red Hat Ansible for provisioning the end-to-end infrastructure in this CVD solution:
https://www.cisco.com/c/en/us/td/docs/unified_computing/ucs/UCS_CVDs/flexpod_baremetal_mlops_openshift_ai.html

This repository contains the Ansible playbooks that will enable you to deploy the following Infrastructure components using Ansible: <br />
&emsp;&emsp; •	 Cisco UCS X-series in Intersight Managed Mode (IMM) <br />
&emsp;&emsp; •	 NetApp Storage   <br />

To execute the playbooks, the FlexPod infrastructure must be first built and cabled.
